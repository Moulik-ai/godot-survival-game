# Last Knight Standing

A fantasy arena-survival roguelite built with Godot and C#.

## About

Last Knight Standing is a fast-paced fantasy arena survival game where you fight endless waves of enemies, defeat powerful bosses, unlock upgrades, earn achievements, and survive for as long as possible.

As the kingdom's final defender, your goal is simple: survive the relentless onslaught and become the Last Knight Standing.

## Features

* ⚔️ Fast-paced combat
* 👹 Multiple enemy types
* 👑 Epic boss battles
* 💎 Level-up and upgrade system
* 🔥 Critical hit mechanics
* ⭐ Elite enemies and bosses
* 🏆 Achievement system
* 📊 End-game statistics
* 🎵 Fantasy-themed visuals and audio
* ⏸️ Pause menu and settings system

## Controls

| Action | Control           |
| ------ | ----------------- |
| Move   | WASD / Arrow Keys |
| Aim    | Mouse             |
| Attack | Left Mouse Button |
| Dash   | Space             |
| Pause  | ESC               |

## Built With

* Godot Engine 4
* C#
* Tiny Swords Asset Pack by Pixel Frog

## Installation

1. Download the latest release from itch.io.
2. Extract the ZIP file.
3. Open the extracted folder.
4. Run `LastKnightStanding.exe`.
